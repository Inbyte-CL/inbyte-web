# Inbyte Web

Sitio web de Inbyte para soluciones de pago electronico, POS MDB, telemetria y dashboards BI para vending, maquinas expendedoras, autoservicio y parking en Chile.

## Comandos

```bash
npm install
npm run dev
npm run build
```
